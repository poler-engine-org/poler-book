## 📌 Содержание и Архитектура
Книга скомпилирована в стандартном формате **EPUB v3.0** и содержит полный исходный код ядра:
1. **`src/` и `crates/`** — Решения непрерывной оптимизации Skew-J, физические операторы каузальной динамики POLER[Ψ], QFT-инварианты на Rust.
2. **`os/`** — Ядро микро-ОС на Zig (IDT, GDT, APIC, VirtIO-GPU, аллокаторы физических и виртуальных страниц памяти).
3. **`tools/`, `benches/`, `proofs/`, `docs/`, `scripts/`** — Инструменты верификации, бенчмарки и математические доказательства.
